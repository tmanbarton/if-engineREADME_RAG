# if-engine RAG Chatbot

I kept forgetting how to use an API I created for myself to create interactive fiction games: [if-engine](https://github.com/tmanbarton/if-engine).
The repo has good documentation so, instead of going to the docs every time I forget something, 
I çreated a CLI chatbot that answers questions about the API using RAG (Retrieval Augmented Generation). Ask it how to use the engine, and it will find the relevant documentation in the repo's README to answer the question.

## How it works

1. `embed.py` reads the if-engine README, splits it into chunks on markdown headings, embeds each chunk using a local sentence transformer model, and saves the result to `index.json`.
2. `chat.py` loads `index.json`, and for each question embeds the query, finds the 3 most semantically similar chunks via cosine similarity, injects them as context into the prompt, and sends it to Claude.

## Files

- `embed.py` — indexes the if-engine README into `index.json`. Run this once, and again whenever the README changes.
- `chat.py` — the chatbot loop.
- `index.json` — generated by `embed.py`. Not checked in.

## Setup

**Install dependencies:**
```bash
pip install anthropic sentence-transformers numpy
```

**Set your Anthropic API key:**
```bash
export ANTHROPIC_API_KEY_CLI_CHATBOT=your_key_here
```

**Build the index:**
```bash
python embed.py
```

`embed.py` will try to read the README from `../if-engine/README.md` first (if you have the engine repo checked out locally as a sibling directory), and fall back to fetching it from GitHub if the local path doesn't exist.

**Start the chatbot:**
```bash
python chat.py
```

Type `quit` to exit.

## Example

```
~ how do I hide an item until the player examines something?
```
